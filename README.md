# Figma Sunum & Demo

15 dakikalık Figma sunum planı — sayfa sayfa slayt formatında, Vercel’de yayınlanmaya hazır.

## Yerel çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) açın.

## Vercel’e deploy

1. [vercel.com](https://vercel.com) → New Project
2. Bu klasörü GitHub’a push edin veya Vercel CLI ile deploy edin:

```bash
npx vercel
```

## Slayt gezinme

| Tuş | Aksiyon |
|-----|---------|
| `→` `Space` | Sonraki slayt |
| `←` | Önceki slayt |
| `N` | Konuşmacı notları paneli |
| Alt noktalar | Doğrudan slayta git |

## İçerik yapısı (13 slayt)

1. Kapak  
2–3. Giriş & Bulut  
4–5. Auto Layout (teori + demo)  
6–7. Components (teori + demo)  
8–9. Prototyping (teori + demo)  
10–11. Dev Mode (teori + demo)  
12. Kapanış  
13. Teknik notlar (hoca)

Slayt metinleri `data/slides.ts` dosyasından düzenlenir.
